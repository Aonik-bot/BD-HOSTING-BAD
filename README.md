# 🚀 AONIK HOSTING Cloud Platform v3.2

High-performance server management and cloud hosting panel with real-time console, file manager, GitHub deployments, CPU rate-limiting, and admin controls.

### 🌟 Key Features:
- 🔐 Single & Multi-tenant auth with **html@gmail** default admin account.
- ⚡ Real-time Console Terminal with live status metrics (CPU %, RAM MB, Net In/Out).
- ⚙️ CPU Rate Limit Engine (30%, 50%, 80%, 100% throttling).
- 📁 Full Virtual File Manager with in-browser Code Editor.
- 🌐 Python (Flask/FastAPI/Telegram/Discord) and Node.js container environments.
- 📦 1-Click ZIP Exporter & Backup Engine.

### 🛠️ Quick Local Setup:
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open `http://localhost:5000`
